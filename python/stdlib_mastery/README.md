# 標準ライブラリ使いこなし Python サンプル

[重要] このフォルダは、サードパーティライブラリ無しで標準ライブラリだけを使いこなす
実務頻出パターンをまとめたものです。

## 実行方法

```sh
cd python/stdlib_mastery
python3 stdlib_essentials.py
```

## 収録モジュール

`os`/`os.path`/`pathlib`（ファイル操作）、`sys`（実行環境情報）、`math`（数学関数）、
`re`（正規表現）、`collections`（`Counter`/`defaultdict`/`namedtuple`）、
`itertools`（組み合わせ・グループ化）、`functools`（`lru_cache`/`reduce`/`partial`）、
`json`（相互変換）。

## 検証環境

- Python 3.14.6 標準ライブラリのみ。追加インストール不要。
- 実行して全出力を確認済み。
